=========================================================
      FACE RECOGNITION API - DEVELOPER DOCUMENTATION
=========================================================
Ye documentation aapko guide karegi ki aap is Python Face 
Recognition API ko apni website (jaise PHP, Node.js, ya kisi 
bhi frontend) ke saath kaise integrate kar sakte hain.

1. API BASE URL
---------------
Jab aap is project ko run karenge (locally ya server par deploy karke), 
toh aapko ek Base URL milega. Localhost par default URL hai:
Base URL: https://python-face-reco-production.up.railway.app/
(Agar server par deploy kiya hai, toh localhost ki jagah production URL use karein)

2. AUTHENTICATION (API KEY)
---------------------------
Har API request me security ke liye ek API key pass karni zaroori hai.
Ise HTTP Headers me bhejna hoga.
Header Name: X-API-Key
Value: <Aapki_API_Secret_Key> (jo .env file me set ki gayi hai)

3. API ENDPOINTS
----------------

A) FACE REGISTER KARNA (POST /api/register-face)
   Is endpoint ka use karke aap kisi naye user/person ka face database me save (register) kar sakte hain.
   - URL: {BASE_URL}/api/register-face
   - Method: POST
   - Headers: X-API-Key: <your_api_key>
   - Body Type: multipart/form-data
   - Parameters:
       - person_id (Text): User ka unique ID (e.g., "EMP001" ya "123").
       - image (File): User ki image file (.jpg, .png etc).
   - Response (Success):
       {
           "success": true,
           "person_id": "EMP001",
           "message": "Face registered successfully"
       }

B) FACE RECOGNIZE KARNA (POST /api/recognize-face)
   Is endpoint ka use face match/verify karne ke liye hota hai (jaise attendance mark karte waqt).
   - URL: {BASE_URL}/api/recognize-face
   - Method: POST
   - Headers: X-API-Key: <your_api_key>
   - Body Type: multipart/form-data
   - Parameters:
       - image (File): Camera se capture ki gayi image ya uploaded image file.
   - Response (Match Found):
       {
           "success": true,
           "matched": true,
           "person_id": "EMP001",
           "confidence": 0.95
       }
   - Response (No Match):
       {
           "success": true,
           "matched": false,
           "person_id": null,
           "confidence": 0
       }

C) FACE DELETE KARNA (DELETE /api/delete-face/{person_id})
   Kisi user ka face data remove karne ke liye.
   - URL: {BASE_URL}/api/delete-face/{person_id}
   - Method: DELETE
   - Headers: X-API-Key: <your_api_key>
   - Response:
       {
           "success": true,
           "message": "Face for person_id EMP001 deleted successfully"
       }

D) TOTAL FACES COUNT (GET /api/faces/count)
   Database me total kitne faces registered hain ye check karne ke liye.
   - URL: {BASE_URL}/api/faces/count
   - Method: GET
   - Headers: X-API-Key: <your_api_key>
   - Response:
       {
           "success": true,
           "total_registered_faces": 15
       }

4. INTEGRATION EXAMPLE (JAVASCRIPT / FETCH API)
-----------------------------------------------
Yaha ek example code hai ki aap Frontend (JS) se API ko kaise call kar sakte hain:

// Face Recognize karne ka function
async function recognizeFace(imageFile) {
    const formData = new FormData();
    formData.append("image", imageFile);

    try {
        const response = await fetch("https://python-face-reco-production.up.railway.app/api/recognize-face", {
            method: "POST",
            headers: {
                "X-API-Key": "YOUR_SECRET_API_KEY" // Apni API key yaha dalein
            },
            body: formData
        });

        const result = await response.json();
        
        if (result.matched) {
            console.log("Welcome User: " + result.person_id);
            // Yaha par aap attendance mark karne ki API call kar sakte hain
        } else {
            console.log("Face not recognized!");
        }
    } catch (error) {
        console.error("API Error: ", error);
    }
}
