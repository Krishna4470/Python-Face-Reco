=========================================================
      LIVENESS DETECTION INTEGRATION GUIDE (PHP)
=========================================================

This document explains how to integrate the newly added Liveness Detection 
(Eye Blink Verification) into your existing PHP Attendance System.

The new system requires the user to prove they are a real person (by blinking) 
before their face is recognized and attendance is marked.

---------------------------------------------------------
1. THE NEW WORKFLOW (Frontend JavaScript -> Backend API)
---------------------------------------------------------

Old Workflow:
Camera -> Take 1 Picture -> Send to `/api/recognize-face` -> Mark Attendance

New Workflow:
1. Camera starts.
2. Prompt user: "Please blink your eyes".
3. Capture a sequence of frames (e.g., 10-15 frames over 2-3 seconds).
4. Capture one final high-quality frame for Face Recognition.
5. Send ALL frames and the final image to `/api/verify-and-recognize`.
6. The Python API will:
    a. Check the sequence of frames for a valid blink (Liveness Check).
    b. Verify that the person who blinked is the SAME person in the final image (Consistency Check).
    c. Recognize the face from the database (Face Recognition Check).
7. If all checks pass, mark attendance in PHP.

---------------------------------------------------------
2. API ENDPOINT DETAILS
---------------------------------------------------------

ENDPOINT: 
POST /api/verify-and-recognize

HEADERS:
X-API-Key: <YOUR_API_KEY>

FORM DATA (multipart/form-data):
- frames: (Array of Files) A list of images captured in sequence (e.g., 5 to 15 frames).
- recognition_image: (File) The final high-quality image used for face recognition.

SUCCESS RESPONSE EXAMPLE:
{
  "success": true,
  "liveness_passed": true,
  "matched": true,
  "person_id": "EMP123",
  "confidence": 0.85,
  "message": "Liveness verified and face recognized successfully.",
  "error": null
}

FAILURE RESPONSE EXAMPLES:
1. Liveness Failed (No blink detected):
{
  "success": false,
  "liveness_passed": false,
  "matched": false,
  "message": "Liveness verification failed. Please blink and try again.",
  ...
}

2. Liveness Passed but Face Consistency Failed (The blinking person and the recognition image are different people - e.g., a photo was held up at the last second):
{
  "success": false,
  "liveness_passed": false,
  "matched": false,
  "message": "Face consistency verification failed. The blinking person does not match the recognition image."
}

---------------------------------------------------------
3. FRONTEND JAVASCRIPT IMPLEMENTATION (Example)
---------------------------------------------------------

You need to modify your attendance page JS to capture multiple frames.

```javascript
let frames = [];
let maxFrames = 10;
let captureInterval;

// Start capturing frames every 150ms when user clicks "Verify Attendance"
function startLivenessCapture() {
    frames = [];
    document.getElementById("status").innerText = "Please blink your eyes...";
    
    let frameCount = 0;
    captureInterval = setInterval(() => {
        let frameBlob = captureFrameFromVideo(); // Your custom function to get canvas blob
        frames.push(frameBlob);
        frameCount++;
        
        if (frameCount >= maxFrames) {
            clearInterval(captureInterval);
            finishCaptureAndSend();
        }
    }, 150);
}

function finishCaptureAndSend() {
    // Capture the final best image for recognition
    let recognitionBlob = captureFrameFromVideo(); 
    
    let formData = new FormData();
    
    // Append all liveness frames
    for (let i = 0; i < frames.length; i++) {
        formData.append("frames", frames[i], `frame_${i}.jpg`);
    }
    
    // Append the recognition image
    formData.append("recognition_image", recognitionBlob, "recognition.jpg");
    
    // Send to PHP Backend OR directly to Python API
    fetch("https://your-railway-app.railway.app/api/verify-and-recognize", {
        method: "POST",
        headers: {
            "X-API-Key": "YOUR_SECRET_KEY"
        },
        body: formData
    })
    .then(response => response.json())
    .then(data => {
        if (data.success && data.liveness_passed && data.matched) {
            // Mark attendance in PHP database using data.person_id
            markAttendanceInPHP(data.person_id);
        } else {
            alert(data.message || data.error);
        }
    });
}
```

---------------------------------------------------------
4. PHP BACKEND IMPLEMENTATION (If calling via PHP cURL)
---------------------------------------------------------
If you are passing the images through PHP cURL instead of Javascript directly:

```php
$url = "https://your-railway-app.railway.app/api/verify-and-recognize";
$ch = curl_init();

// Build multipart array with multiple frames
$postFields = [
    'recognition_image' => new CURLFile($_FILES['recognition_image']['tmp_name'], 'image/jpeg', 'rec.jpg')
];

// Loop through uploaded frames and attach them
foreach ($_FILES['frames']['tmp_name'] as $index => $tmpName) {
    $postFields['frames['.$index.']'] = new CURLFile($tmpName, 'image/jpeg', 'frame_'.$index.'.jpg');
}

curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $postFields);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "X-API-Key: YOUR_SECRET_KEY"
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
if ($result['success'] && $result['liveness_passed'] && $result['matched']) {
    echo "Attendance Marked for: " . $result['person_id'];
} else {
    echo "Error: " . ($result['message'] ?? $result['error']);
}
```
